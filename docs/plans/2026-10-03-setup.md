### Task 5: Godot project (issue "Create the Godot project")

**Files:**
- Create: `project.godot`, `scenes/main/main.tscn`
- Create: `.gitkeep` in `scenes/fighter/`, `scenes/player/`, `scenes/enemies/`, `scenes/levels/`, `systems/combat/`, `systems/input/`, `systems/camera/`, `systems/enemies/`, `data/moves/`, `assets/sprites/`, `assets/tiles/`, `assets/ui/`, `assets/music/`, `assets/sfx/`

**Step 1: Take the issue.** With `I` the issue number from Task 2:

```bash
gh issue edit I --add-assignee beben-games
git switch -c code/I-godot-project
```

Move it to **In progress** on the board (`gh project item-edit`, using the item id from `gh project item-list` and the Status option id from `gh project field-list`).

**Step 2: Write the failing check.** Run: `godot --headless --path . --quit-after 10; echo "exit $?"`. Expected: fails, because there is no `project.godot`.

**Step 3: Create `project.godot`.**

```ini
; Engine configuration file.
; Edit it through the Godot editor's Project Settings where possible.

config_version=5

[application]

config/name="Untitled beat 'em up"
run/main_scene="res://scenes/main/main.tscn"
config/features=PackedStringArray("4.7", "GL Compatibility")

[display]

window/size/viewport_width=480
window/size/viewport_height=270
window/size/window_width_override=1920
window/size/window_height_override=1080
window/stretch/mode="viewport"
window/stretch/scale_mode="integer"

[rendering]

textures/canvas_textures/default_texture_filter=0
renderer/rendering_method="gl_compatibility"
renderer/rendering_method.mobile="gl_compatibility"
```

**Step 4: Create `scenes/main/main.tscn`.**

```
[gd_scene format=3]

[node name="Main" type="Node2D"]
```

**Step 5: Create the folders.**

```bash
for d in scenes/fighter scenes/player scenes/enemies scenes/levels \
         systems/combat systems/input systems/camera systems/enemies \
         data/moves assets/sprites assets/tiles assets/ui assets/music assets/sfx; do
  mkdir -p "$d" && touch "$d/.gitkeep"
done
```

**Step 6: Run the check.**

```bash
godot --headless --path . --import 2>&1 | tee /dev/stderr | grep -c "ERROR"
godot --headless --path . --quit-after 10; echo "exit $?"
```

Expected: `0` errors, then `exit 0`. If Godot rewrote `project.godot` on import, keep its version. Confirm `git status --short` shows no `.godot/` files.

**Step 7: Commit and open the pull request.**

🤖 Generated with [Claude Code](https://claude.com/claude-code)"
